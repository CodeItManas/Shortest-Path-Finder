# Shortest Path Finder – Interactive Pathfinding Visualizer

## Overview

Shortest Path Finder – Interactive Pathfinding Visualizer is a web-based application that demonstrates how shortest path algorithms work through real-time visualization. Users can create obstacles, define start and destination nodes, and observe the algorithm finding the optimal path step by step. The project is designed to make learning graph algorithms simple, interactive, and engaging.

## Features

- Interactive grid-based visualization
- Create and remove obstacles
- Select start and destination nodes
- Real-time pathfinding animation
- Clear path and reset grid functionality
- Responsive and modern user interface
- Smooth animations and improved user experience

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Shortest-Path-Finder.git
```

Navigate to the project directory:

```bash
cd Shortest-Path-Finder
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm start
```

The application will be available at:

```
http://localhost:3000
```

## How to Use

1. Launch the application.
2. Place the start and destination nodes.
3. Draw obstacles by clicking on the grid.
4. Select the desired algorithm (if available).
5. Click the Visualize button.
6. Observe the shortest path animation.
7. Use Clear Path or Reset Grid to perform another visualization.
